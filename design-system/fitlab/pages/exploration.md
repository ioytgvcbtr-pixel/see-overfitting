# 0.8 · 模型探索地图

面向高校机器学习初学者，视觉主题是可以动手的模型花园。入口用一张可选择的概念岛屿地图组织问题，实验页将空间让给图形和当前证据。

## 令牌

| 用途 | 色值 |
|---|---|
| 文字与导航 | #28213D |
| 模型与主操作 | #7546C8 |
| 训练与探索状态 | #087E75 |
| 验证与提示 | #B84B2C |
| 地图任务高光 | #F6D66F |
| 主背景 | #F6F3FC |

中文继续采用本地Microsoft YaHei UI/PingFang SC，数字使用Bahnschrift/Segoe UI。标题34～40px，正文14～16px，辅助文字至少12px。无需远程字体。地图上的抽象曲线和岛屿是导航图形，不编码实验指标。

## 布局

```text
学习导航 | 简短开场：从哪个问题开始
         | 可选择的岛屿地图     | 当前问题、怎么操作、进入按钮
         | 错分侦探入口         | A/B对照入口
```

地图采用非等宽的有机形状，配方和引导使用开放排版。现有Q版向导出现在所选问题旁；其余界面保持克制。实验页压缩重复介绍，指标前移；统一选中、待更新、揭晓和恢复状态。

桌面地图旁放步骤，手机地图采用可点击的双列岛屿布局，步骤随后呈现。控件至少44px高，拖幕同时有原生范围滑块；新功能可从文本按钮使用，不依赖悬停。只在用户选择或操作时反馈动效，遵循prefers-reduced-motion。
