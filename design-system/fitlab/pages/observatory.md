# 科学探索馆视觉覆盖

本页设计覆盖旧版浅蓝卡片外观，适用于0.5全部工作区。功能约束、数据语义与无障碍规则继续有效。

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 | #F8F7FC | 明亮纸面 |
| 导航 | #27213F | 稳定的深紫课程导航 |
| 正文 | #25213B | 大标题与正文 |
| 主操作 | #7044D6 | 预测、焦点、当前步骤 |
| 实验 | #087E83 | 训练与实际计算 |
| 验证 | #BC4935 | 验证样本与偏离假设 |
| 路径辅色 | #F0BB4D | 非文字的暖色节点 |

次级正文#615B75；输入边界#8D839F。中文使用Microsoft YaHei UI/PingFang SC/Noto Sans CJK SC；数值使用Bahnschrift/Segoe UI，保留等宽数字。字号14/16/20/30/44，大标题明确、辅助文字不低于12px。

记忆点是课程标题旁的曲线学习航线。三个节点对应真实预测、实验和迁移阶段，允许跳到已经解锁的区域；未解锁节点不提供结果。节点是圆形，记录是开放行，参数与绘图共享连续画布。其他区域保持克制，避免给每段文字另加外框。

预测选项使用带圆形标记的开放横排，选择以颜色、标记和文字共同体现。反馈使用细色线与文字，不用大量嵌套矩形。用户点击触发的细微变化可以保留，减少动态效果时即时呈现。
