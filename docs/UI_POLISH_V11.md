## 设计取舍

面向机器学习初学者，保持四岛插画、真实操作与清晰焦点，让排版承担分组。品牌仍为梅紫#30263D、紫#7546C8、青绿#087E75，背景#F8F9FC，纸面#FFFFFF，次级正文#6B6175。使用现有系统中文字体；数字启用tabular-nums与固定槽位。字号延续12/14/16/22/30，标题使用balance。

```text
岛名与一个学习问题
三个主题入口
训练样本数量              数据条件 ?
场景及实算读数            当前控制与任务 ?
精确图表（展开）
```

1. 数字：等宽数字贯穿控件、图表和读数，动态输出固定宽度；读数使用固定网格，数字变化不会推挤相邻指标。
2. 同心圆角：场景容器内边距20、内场景圆角20、外圆角40；手机为12+16=28。课程封面贴边时内外圆角一致。按钮为控件，不机械当成嵌套卡片。
3. 分组淡入：页面进入时按0/100/200/300ms错开，使用opacity，不移动交互坐标；调参不重播数值动画。减少动态效果时即时显示。
4. 标题：使用text-wrap:balance和自然换行，不强制不可断中文块；验证窄屏。
5. 表面：使用低透明度、多层柔和阴影，替换容器硬边框；输入边界、焦点、图例和科学坐标继续表达功能。保留自然底色和足够留白。

删除重复的“动手观察/探索任务/玩法预告”等标签，将场景读法、比较范围和操作说明集中到相应区域的问号。问号支持悬停、聚焦、点击/轻触、Esc和点击外部关闭；使用顶层popover避免被卡片裁切，位置限制在视口内。任务当前目标、实算/更新状态、真实数值与错误反馈仍直接可见。

## 已实现与复核

桌面40=20+20、手机28=16+12；读数在符号和位数改变后槽位仍固定；分组延迟实测0/0.1/0.2/0.3s，减少动效时为none/0s。问号支持完整的悬停、焦点、固定与关闭，并随内容变化避让。首页操作说明同步到当前岛内对象，冗余文本视觉隐藏、辅助描述保留。

浮层曾按包含滚动条的innerWidth定位，改为实际内容宽后390px iframe为59～359/375，320px为16～289/305，两侧至少16px。选择状态与输入边界保留3:1以上的所选颜色对比；阴影用于表面层级。实际范围见[验收](VALIDATION_V11.md)。
