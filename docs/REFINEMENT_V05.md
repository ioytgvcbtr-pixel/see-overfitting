# 0.5：学习可回看，界面像一座科学探索馆

用户反馈：继续完善学习与实验环节，减少矩形框、改善单调配色，形成有辨识度的前端。保留真实Git与AI记录，提交材料继续暂缓。

## 逐项处理

| 环节 | 当前断点 | 本轮落实 |
|---|---|---|
| 预测 | 进入页面仍像填写后台表单 | 显示真实学习阶段的曲线航线；开放式预测选择与简短概念提示 |
| 参数实验 | 三步都可点，但下一步不够突出 | 根据实际观察标出下一组；完成后直接进入迁移区域 |
| 迁移验证 | 历史预测、错答与重试藏在存储中 | 学习足迹可回看、继续；更换未使用的种子重新预测 |
| AI实验 | 不支持预期后仍停留在执行后参数 | 一键恢复执行前条件或回看执行后条件；原核验记录保持不变 |
| 真实数据 | 离开模块或刷新会丢失正在研究的条件 | 记住当前数据集、模型、参数与展示方式，重新实算而非套用旧指标 |
| 证据记录 | 刷新会使本页记录ID丢失 | 报告从后端按本轮学习ID补齐已执行方案，保持条件一致性 |

## 前端设计

方向为“科学探索馆”：深紫导航与明亮纸面，紫/青/橙分别对应预测、实验、验证；主画布使用训练青色与验证橙色的既有语义，并保留点形状区别。开放式排版、曲线和环形节点组织层次，仅绘图区与模态框保留明确容器。

```text
深紫课程导航 | 大课程标题              曲线学习航线
             | 开放式预测选择 / 实际指标带
             | 连续的实验画布           参数操作带
             | 实际对照 → 原预测复盘 → 新数据验证
             | AI单变量实验与可逆参数操作
             | 学习足迹、核验记录、原始实验记录
```

设计复核：首次技能检索偏黑白展馆，第二次偏儿童厚边卡片，均与高校用户和本次反馈不符。采用可用的可读性、键盘、触控与减少动效规则；视觉选择依据本项目主题另行设计。保留系统中文字体与代码原生SVG，避免远程字体和装饰性滚动动效。

参考观察：[Mathigon](https://mathigon.org/)用数学图形与多色表达学习主题；[Explorable Explanations](https://explorabl.es/)以开放叙事和可交互图形组织学习。只借鉴组织方式，不复制页面资产、文案或模板。课程航线由真实阶段驱动，不显示未提交预测的实验结果。

## 验收

核验历史不泄露未提交题目答案；重练种子与已有记录不同；报告只关联本轮已执行方案；恢复参数不改写原对照。检查桌面与375px内容区、键盘、焦点、色彩对比与减少动态效果。所有指标仍来自数值后端，不把开发验收当作学生试用研究。
