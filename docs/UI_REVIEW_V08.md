# 0.8界面自评、参考观察与改进

## 改动前自评

面向初学机器学习的高校学生。0.7的数值与操作已齐备，但从首次进入到持续探索仍有断点：

| 观察点 | 当前问题 | 本轮落实 |
|---|---|---|
| 首次进入 | 导航以功能命名，用户要自己判断先做什么 | 新增默认探索地图，用问题与任务进入实验 |
| 视觉层级 | 同样的浅紫大容器与长页面重复出现，重要性接近 | 地图作为主要识别画面；实验页收紧介绍，指标靠近画布 |
| 内容展示 | 图、关键数值和解释常分处不同滚动位置 | 分类指标前移，控件与画布形成连续操作区 |
| 玩法 | 主要靠自由调参，缺少明确寻找目标 | 错分侦探、A/B拖幕对照、可直接开始的实验配方 |
| 结果反馈 | 切换模型后难记住刚才的图，错分直接被×揭示 | 定格同数据的实算A；侦探先寻找再反馈 |
| 插画与引导 | Q版角色主要作为静态装饰 | 角色与当前所选问题、操作步骤相邻 |

以上是开发自评和实际页面观察，不作为学生访谈或学习效果证据。

## 参考与取舍

- [The Evolution of Trust](https://ncase.me/trust/)：实际查看开场与分步叙事，把一个具体问题和下一步行动放在同一画面。采用短任务与逐步反馈，不复制文字或资产。
- [Polypad](https://polypad.amplify.com/p)：实际查看进入选择、开放画布与周边工具。采用画布优先和按需工具层级。
- [Brilliant](https://brilliant.org/)：核对当前公开页面的共享画布、引导问题与反馈说明。采用提示紧邻操作；未访问需登录的课程，不声称测试过付费功能。
- UI/UX Pro Max检索用于核对触控、拖拽替代、焦点和反馈。项目沿用已有高校用户字体和语义配色，不引入未经验证的用户评价或营销转化模块。

## 实施边界

1. 地图是导航示意；进入实验后的数值、类别、边界和结果仍来自后端。
2. 侦探仅判断当前验证样本，按当前后端预测核验；本地探索不计正式课程成绩。改变条件后重新核验，不把旧发现带入新结果。
3. A/B仅在数据指纹及坐标范围一致时启用。左右各自显示对应模型的边界与预测标记；两份指标均来自已返回的实算结果。
4. 所有拖拽同时提供点击/滑块/键盘替代；减少动效设置下不加入持续动画。
5. 原正式学习轮次和记录继续保留，比赛材料仍暂缓。实机验收使用独立浏览器来源保存探索草稿，避免改写原工作区草稿。

## 落实后的自检

默认入口已改为可选问题的地图，实际阶段由地图→问题说明→操作画布→证据反馈组成。分类增加自由、侦探、A/B三种模式；探索计数来自当前实算中的真实错分，A/B左右判断与各自模型一致。复制记录包含探索上下文，正式课程成绩仍独立。

视觉上减少重复介绍和课程导航，分类指标前移，工具围绕画布；Q版向导与岛屿、步骤说明形成整体。窄屏保留四个可点击岛屿和可阅读的任务说明。新的界面层级与玩法已经实际验收，但教学效果和目标用户偏好仍需真实试用。

实机修正了标题不可断片段造成的横向溢出、菜单快速Esc关闭失败，以及侦探只读状态与旧提示不一致。最终地图和A/B页面在五档宽度下均无页面横向溢出；详细命令、结果与截图见VALIDATION_V08.md。
