# 形成性试用流程

用途：可选的教学研究参考，独立于作品验收和比赛交付。实施研究时，开发者验收、AI模拟与自动回归不能替代学生反馈。

面向3–5位了解回归但尚未掌握正则化的初学者，单次约15分钟。使用匿名编号，不采集姓名、学号或联系方式。征得参与同意；任何时候可以停止。不开启屏幕录制，除非参与者另外同意。

1. 无口头提示，从首页开始误差湖，记录找到入口的时间与第一次卡住位置。
2. 完成“预测→实验→迁移”。观察是否分清训练与验证；记录首答、提示次数、恢复是否成功。
3. 在花园自主选择第一次α，找出系数收缩而验证变差的反例。允许失败；记录是依据两个真实读数判断，还是只按按钮提示行动。
4. 完成新数据迁移后，用自己的话解释“更强约束为什么不等于更准”。这不是记忆选项，观察员只记录原话与是否提到独立的验证证据。
5. 任选一次已提交的错误依据，让AI建议一个实验并执行，询问参与者能否分清待验证假设、实际结果及不确定预期。

只报告观察到的问题及修改，不从3–5人的试用推断教育效果，也不把第二次答对覆盖第一次错误。

异机复现另记操作系统、已有运行时、网络、全新克隆、依赖安装、构建、首页就绪和一次离线学习完成的实际时间。GitHub Windows流水线的范围是预装基础工具的全新托管虚拟机，不能等同所有学生电脑。
