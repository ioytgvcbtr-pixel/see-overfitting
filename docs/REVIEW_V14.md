## 内容质量的实际短板

1. backend/islands.py的REASONS每岛固定三句，错误项多为“必然/只要”式绝对判断，正确项通常更完整。只打乱位置不足以排除靠措辞作答，迁移通过不能直接证明理解。
2. 四岛主要按4岛×2模式×3种子组织有限任务，迁移主要换种子/模式。自由参数空间很大，但正式题目的表达形式和推理路径有限，两者不能混称丰富题库。
3. 入门任务要求到达指定完整目标参数，适合建立可控对照；进阶层还缺学生提出假设、选择一个变量、自行找反例的实验设计任务。
4. 曲线变化RMS测的是本次扰动的敏感性，不能直接当作统计方差或过拟合的充分证明。分类模型适配问题也不全等于过拟合，应持续围绕训练与新数据表现组织主线。
5. 岛内AI目前读取首次预测和观察证据，尚未将迁移错因/选错依据系统地用于诊断。若只给通用调参建议，其教学特色仍不够集中。
