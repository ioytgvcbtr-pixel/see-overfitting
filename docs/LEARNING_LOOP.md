# 预测、实验与可核验建议

本轮产品迭代：先提交预测，再展示结果；完成同条件三步对照后，在新种子数据上做迁移验证。提交材料继续暂缓。

## 学习流程

```text
预测哪个条件验证误差最低 + 信心 + 理由
    ↓ 提交后锁定本轮预测
同条件实验 → 三份后端实算记录 → 预测与实际对照
    ↓
新的随机种子与参数组合 → 选择模型 + 判断依据
    ↓ 后端判分
通过则记录本轮完成；未通过保留反馈，再换一组数据重试
```

学习记录存入本地SQLite，包含预测时间、条件、实际指标、迁移题与首次/重试作答。更改固定条件会开启新一轮预测。刷新可恢复本轮；旧版练习完成状态不冒充新闭环完成。

## AI实验操作

模型从后端提供的合法单变量候选中选择一个方案，并提出可被检验的方向预期。界面展示原值、目标值、固定条件和假设，用户点击后才执行。

后端按已保存方案重算前后结果，不执行模型生成的代码，不读取测试指标。核验使用实际验证误差，可能支持或不支持预期；无方向假设只记录观察。条件变化后的旧方案不能执行。接口或格式错误明确显示规则建议。

执行结果保留前后参数、指纹、指标、方向和时间；AI解释与实验假设分开标记。基础课程与三个公开数据集共用操作组件。设计沿用现有浅蓝科学画布与可读字体，步骤编号仅用于真实流程，不增加装饰性动效。

## 验收重点

- 预测提交前不请求或显示该课程的计算结果，迁移答案不会提前返回。
- 未完成三步不能提交迁移；错答不计完成，同题重复请求不重复计次。
- 迁移使用新数据；测试集不参与；旧预测和固定条件不混用。
- 一键方案只改变一个合法变量，旧条件拒绝执行，前后指标可独立重算。
- 模型错误建议、API失败、请求取消和刷新恢复有实际验证。
- 保留真实Git与脱敏公开过程，不将开发验收当成学生学习效果研究。
