# AI开发过程证据

本目录记录真实发生的用户指令、AI公开回应、代码迭代、工具反馈和对应提交。完整公开消息与工具过程由`scripts/export_ai_process.py`从当前会话读取并脱敏导出。

- `conversation.md`：公开用户/助手消息，凭据替换为[REDACTED]。
- `tool-events.jsonl`：本次实现期间实际工具调用与输出，排除内部推理、系统及开发者指令。
- `iterations.md`：按功能归纳的真实实现链及Git锚点。

公开记录采用相对路径、环境占位符和会话标识规范化；原始记录保留在本机会话存储或忽略目录中，不进入仓库。脚本验证嵌套JSON结构后更新记录。

续跑产生多个日志分段时，使用`--session <原会话日志> <续跑日志>`传入本项目的相关分段。脚本按时间合并，去除完全相同事件及分段交接时两秒内相同的重复消息，保留稍后重新输入的相同Prompt和不同的工具输出片段。不能只选择文件名以原会话标识结尾的旧文件；0.7已核对本轮模块标记，补入本轮实际过程。

外部设计参考仅保留检索和页面地址，省略网页正文和账户画面输出；本项目浏览器操作、失败反馈和修正继续保留。编码后的本地file URI也执行规范化。

固定插画的生成提示词和资产用途另存public/illustrations/README.md；过程导出省略生成预览的二进制内容，保留调用及项目素材。工具未返回具体模型版本时，不补写推测版本。

实现子任务是AI对用户总指令的拆解，不能标为用户逐字输入。记录只证明当前AI辅助开发过程；参赛者亲自提出的后续修改、调试和录屏应继续追加。不得重写历史伪造多轮用户Prompt。
