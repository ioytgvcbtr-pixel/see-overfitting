# 核心概念工坊

本轮聚焦“操作—内部量—图形—解释”联动，让抽象概念可以通过拖拽和滑块观察。保留原学习轮次与独立测试协议，提交材料继续暂缓。

## 参考观察与技术选择

| 参考 | 可借鉴的机制 | 本项目落实 |
|---|---|---|
| [TensorFlow Playground](https://playground.tensorflow.org/)及[官方源码](https://github.com/tensorflow/playground) | 参数、模型内部表示与输出相邻联动；官方README确认TypeScript与D3 | React协调输入和实算结果，保留固定条件 |
| [Seeing Theory回归](https://seeing-theory.brown.edu/regression-analysis/index.html) | 页面已归档；拖点、回归线、平方误差与参数表联动 | SVG点拖拽、残差与选中误差平方 |
| [Distill：Why Momentum Really Works](https://distill.pub/2017/momentum/) | 可操纵的几何图、参数与公式对应，图形承担解释 | Canvas损失地形与线性模型双向操纵 |
| [Setosa：OLS](https://setosa.io/ev/ordinary-least-squares-regression/) | 最小二乘的几何表达 | 用实际残差与平方项解释MSE |

采用React + SVG + Canvas 2D。二维回归、误差和系数用这套组合即可表达；本轮不增加Three.js依赖。借鉴交互组织方式，图形和代码自行实现，不复制页面资产。

## 三个可操作面板

1. **残差与损失地形**：上下拖训练点；在地形上拖动斜率/截距标记，联动拟合线、残差和平方项；可移到后端算出的最小二乘解。
2. **样本扰动与过拟合**：同一扰动同时作用于低阶与可调阶数模型；叠加原始/扰动曲线，比较实际曲线变化RMS和验证误差。变化未必随阶数单调，结论取自本次计算。
3. **正则化与系数**：对数α滑块联动拟合与标准化特征系数；显示系数范数、训练SSE、α‖w‖²与目标和，并以同一数据上的系数路径解释约束。单个系数未必单调。

## 数据与交互边界

工坊使用独立探索数据，和学习轮次分开，不计入迁移成绩。训练点可编辑，验证样本不允许拖动，测试指标不返回。标准化仅拟合当前训练X。所有显示的误差、系数与地形值由后端计算。

Pointer Events统一鼠标和触摸，选点及滑块提供键盘替代。拖动时保留即时点位预览，限频请求并忽略过时响应；指标只有匹配当前输入才显示为当前值。坐标裁切明确提示，重置恢复原始样本。

同时修正高阶强正则的诊断边界：训练与验证误差均偏高时，不给绿色“较平衡”结论。诊断保持教学提示属性，不冒充统计检验。
