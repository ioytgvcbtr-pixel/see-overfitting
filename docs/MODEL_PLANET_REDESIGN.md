# 模力星球：机器学习教学平台重定位与改进方案

日期：2026-11-16。阶段：产品与技术设计，待分期实施。设计基线：当前0.16版，代码与验收记录保持原样。本轮交付本方案，不直接替换运行中的网站，也不制作竞赛视频或提交PDF。

## 1. 定位与命名

**网站名称：模力星球。**

**副标题：机器学习实验课堂。**

**主标语：让每次选择，都看见结果。**

“模”对应模型，“模力”带有魔力的谐音，强调亲手尝试产生变化；“星球”承接已有群岛、场景与Q版角色，适合逐步探索多个模型。品牌面向大学生与研究生，形象活泼，内容表达保持专业。英文辅助名采用Model Planet。

项目主线从一个泛化概念扩展为：**学生亲手完成一次分类或回归任务，能解释自己的数据处理、划分、模型和参数选择如何影响结果。**

标识采用“M形轨迹＋样本点＋环绕轨道”的原创SVG方案，向导称为“小模”。品牌图案负责识别和引导，实验数值仍由真实模型给出。

原有过拟合、正则化、敏感性、分类边界内容进入“模型机制工坊”，成为完整课程中的章节。原数据、真实Git历史、AI记录、旧学习成绩继续保留。

### 学生完成课程后应具备的能力

1. 根据要预测的目标判断分类或回归，而不是仅凭目标列是不是数字判断。
2. 识别缺失、重复、异常、类别变量及不同特征尺度，并制定处理方案。
3. 自行设置训练、验证、测试比例，解释各部分的用途。
4. 选择合适的模型，填写合法参数，知道参数的控制作用。
5. 通过训练/验证指标、可视化和受控对照判断结果，不只追求训练集分数。
6. 在最终评估后如实区分已探索结果与未接触测试的评估，能复现一次实验。

## 3. 课程体系：任务类型与算法家族分开组织

### 3.1 两条主线

| 主线 | 基础任务类型 | 后续进阶 | 入门问题 |
|---|---|---|---|
| 分类港 | 二分类、多分类 | 多标签分类 | 给一个新样本预测哪个类别？ |
| 回归谷 | 单目标数值回归 | 多目标回归、计数目标、带时间顺序的预测任务 | 给一个新样本预测多少？ |

多分类指每个样本属于多个候选类别中的一个；多标签指一个样本可以同时具有多个标签。多目标回归同时预测多个数值。时序是数据依赖与评估方式，不作为与随机森林并列的算法名。

同一数据集可以有不同任务定义。例如葡萄酒可预测评分，也可依据事先明确的评分规则构造类别任务；目标变换必须单独版本化，评分任务的RMSE与分类任务的F1不直接排名。

### 3.2 完整首版模型目标：12个

| 方向/家族 | 模型 | 学习重点 | 当前基础 |
|---|---|---|---|
| 分类·线性判别 | 逻辑回归 | 线性边界、约束、概率估计 | 已有 |
| 分类·概率生成 | 高斯朴素贝叶斯 | 按类统计、条件独立假设 | 新增 |
| 分类·邻近方法 | K近邻分类 | 邻居投票、距离、局部复杂度 | 已有 |
| 分类·核方法 | RBF SVM分类 | C、γ与边界形状 | 已有 |
| 分类·树模型 | 决策树分类 | 切分、树深、叶节点 | 已有 |
| 分类·集成 | 随机森林分类 | 多树投票、复杂度与稳定性 | 已有 |
| 回归·线性关系 | 普通线性回归 | 系数、截距、预测与残差 | 新增 |
| 回归·正则化线性 | 岭回归 | α、系数收缩、泛化 | 已有 |
| 回归·邻近方法 | K近邻回归 | 邻居平均、局部预测 | 新增 |
| 回归·核方法 | RBF SVR | 非线性拟合、C、γ、ε | 新增 |
| 回归·树模型 | 决策树回归 | 分段预测、深度与泛化差距 | 已有 |
| 回归·集成 | 随机森林回归 | 多树平均与单树对照 | 已有 |

均值回归基线和多数类分类基线继续提供，作为最低限度的比较对象，不混入12个主要模型计数。

第二阶段优先增加Lasso、ElasticNet及分类/回归梯度提升。多项式特征作为特征变换配合线性/岭回归教学；多特征高阶展开要预估生成列数并设置计算上限。原有一维机制工坊的1～15阶单独保留。

## 4. 学习流程与信息架构

全局导航收拢为：**开始学习、分类任务、回归任务、模型图鉴、我的实验**。数据体检、清洗、划分和训练是一次任务中的连续步骤，不再各自形成互相脱节的全局入口。

每个任务都采用同一条流程：

| 步骤 | 学生做的决定 | 系统给出的实际反馈 |
|---|---|---|
| 认识任务 | 选择目标，判断分类/回归 | 解释目标和输入、单位、成功标准 |
| 数据体检 | 查看数据质量与特征，选择输入列 | 缺失/重复/类别/常量等计数，哪些列参与模型 |
| 制定清洗方案 | 选择填补、编码、缩放、异常处理 | 展示待执行操作及适用条件，不提前拟合全量统计量 |
| 划分数据 | 填三项比例、种子、合法划分方式 | 目标/实际样本数、类别分布、分组约束 |
| 模型与参数 | 选模型，填核心参数，写预测 | 范围校验、模型适用性、完整有效配置 |
| 训练与验证 | 提交当前配置 | 真实计算阶段、指标、预测、残差/边界 |
| 对照与解释 | 定格A，改变一个因素运行B | 条件差异、可比性、指标变化与证据定位 |
| 最终评估与迁移 | 锁定配置评估测试集，再做新情境 | 测试接触状态、独立新题、可恢复实验档案 |

界面先让学生计划清洗，实际统计拟合发生在划分之后：

```mermaid
flowchart LR
  A[原始快照与任务定义] --> B[体检与清洗方案]
  B --> C[按角色划分样本]
  C --> D[只从训练集学习清洗/缩放/编码]
  D --> E[训练模型]
  E --> F[变换验证集并评估]
  F --> G[预测-实验-对照与解释]
  G --> H[锁定配置]
  H --> I[最终测试评估]
  I --> J[新情境与实验归档]
```

训练前保留学生的预期，如“树深增加后验证误差会怎样”。需要评分时，沿用先锁判断、再选依据的协议，不提前显示正确答案。

### 5.3 数据版本规则

- 原始快照只读，保留来源、许可、文件校验值、列含义、目标与单位。
- 清洗和特征选择产生派生配置，不改写原始文件；结果保存所用行标识和配置指纹。

- 多目标数据按目标分别展示指标，单位以源说明核定；未核定的单位不自行补造。

## 6. 知识入门：短讲解与立即操作相连

每个模型设置一页入门卡：解决什么问题、如何作出预测、最重要的两三个设置、一次真实小实验、一个容易误判的情境。学生看完机制就进入同一任务的参数填写，不跳到另一个独立演示系统。

| 主题 | 可以直接操作的内容 |
|---|---|
| 分类与回归 | 将目标卡片放入两条任务轨道；解释数值类别标签仍可能是分类 |
| 特征与目标 | 拖入特征篮、选择目标列，观察输入和输出的变化 |
| KNN | 高亮真实训练邻居及投票/平均，不用装饰邻居冒充计算结果 |
| 线性与岭回归 | 选择真实系数项，联动预测和残差 |
| SVM | 使用当前模型的边界或条件切片，观察C/γ改变后的结果 |
| 决策树 | 展开实际拟合树的前几层，追踪一个样本的路径 |
| 随机森林 | 展示真实单树预测与集成结果；默认只抽取少量树作解释 |
| GaussianNB | 展示训练数据按类得到的统计和假设，输出模型概率估计 |

机制示意图与本次实算图分清用途。学习卡中出现的示意数值不进入实验指标或成绩。

## 7. 数据清洗：学生选择方案，系统执行并说明影响

### 7.1 可选择的操作

| 操作 | 初版提供的选择 | 学生观察什么 |
|---|---|---|
| 缺失数值 | 保持、训练均值、训练中位数、常量填补 | 样本可用性、填补值、分布和预测变化 |
| 缺失类别 | 保持、训练众数、显式缺失类别 | 类别数量与未知值处理 |
| 删除缺失行 | 仅针对训练行的策略，受评估可用性检查约束 | 有效训练样本减少与结果变化 |
| 重复记录 | 保留、训练内去重 | 权重/样本数变化；重复组始终不跨集合 |
| 异常特征 | 不处理、训练分位截尾；后续加IQR训练行筛选 | 极端值对不同模型的影响 |
| 数值缩放 | 不缩放、标准化、Min-Max；后续RobustScaler | 距离/核/线性模型的结果变化 |
| 类别编码 | One-Hot；后续显式有序编码 | 名义类别不自动当有距离的数字 |
| 特征选择 | 勾选训练输入列，排除目标/ID | 信息增减、训练成本与泛化变化 |

“保持缺失”在模型不能接受缺失时产生可解释的校验反馈。不会伪造一次成功训练。常量填补值由学生填写；均值/中位数由训练数据实际计算。

上述填补针对输入特征。目标缺失的行不能填一个标签或评分后参加评估，应单列为待预测样本，或在定义监督可用人群时排除并记录为新数据版本。

### 7.2 统计边界

原始解析、列角色和结构检查先完成；需要学习统计量的步骤在划分后执行。填补值、缩放范围、编码词表、异常截尾阈值只从训练部分拟合，随后应用到验证/测试。交叉验证时也在每个训练折中重新拟合。[S2]

体检主要展示结构与质量计数；逐行误差诊断在角色划分后按训练/验证开放，测试诊断在最终评估后解锁。

删除训练行不能顺便删除验证/测试中的难样本。若评估数据存在当前方案无法处理的缺失，应提示切换到可应用的处理方法，不能静默跳过再计算漂亮分数。全列缺失、未知类别及无有效特征要给出具体原因。

去重需要区分完全相同的记录与相同输入但目标不同的冲突观测：后者展示冲突，不按预测是否正确擅自选保留标签。分组约束依据源实体/原始输入记录建立，不用目标来挑选划分。Min-Max使用训练范围时，验证值可能落到0～1之外，不为美化图像自动裁回范围。

清洗结果展示同一训练行的处理前后、实际学习到的填补/缩放信息、保留和丢弃的样本数。任何导致评估群体改变的处理都要标记为新的数据版本，不能直接宣称是同样本效果提升。

## 8. 训练/验证/测试划分：三项数值由学生填写

### 8.1 表单规格

| 字段 | 初始值 | 拟采用的课堂约束 |
|---|---|---|
| 训练比例 | 空 | 20%～90%，整数 |
| 验证比例 | 空 | 5%～40%，整数 |
| 测试比例 | 空 | 5%～40%，整数 |
| 实验种子 | 空 | 0～999999，整数 |
| 划分方式 | 待选择 | 回归随机；分类随机或分层；实体/重复组不能跨集合 |

三项合计必须100%。这些是教学版采用的范围，不代表数学上所有可能的划分。表单显示还需分配多少；不自动替学生补余数。

输入完成后预览目标比例、实际人数/条数、类别构成与分组约束。相同实体或重复输入组不会被拆开；因此实际行数可能偏离目标比例。分组键不取目标标签；特征子集造成的偶然相同值不自动等同于同一实体。

学生选“随机”时使用普通随机或按组随机；选“分层”且存在分组时采用可行的组级近似分层，并在预览中显示实际方法。单个实验种子控制可复现的划分、子集选择与模型随机性，派生子种子的规则固定并写入记录，不随请求重新抽取。

普通随机/分层可用两阶段拆分；重复实体采用分组拆分及类别覆盖检查，必要时使用确定性候选分配寻找可行解。`GroupShuffleSplit`的比例针对组而非行，不能拿组比例冒充精确行比例。[S4] 分类每部分需要覆盖课程所需类别，不可行时阻止训练并说明缺哪类、缺多少。时间依赖数据在进阶课程中采用时间顺序拆分。

### 8.2 两种不同的实验含义

1. **重新划分数据**：改变比例或种子后，训练和评估样本都可能改变。可观察结果，但系统不能把指标差异全部归因到训练样本量，也不直接判定A/B胜负。
2. **固定评估集的数据量实验**：先冻结一次划分，再从训练池使用10%～100%的样本，验证/测试身份保持。这个选项单独叫“训练样本使用比例”，不与三份划分比例混淆。

数据量实验的每个比例都从原始快照取确定性子集，再单独拟合完整处理与模型流水线。不能先用100%训练池拟合填补、编码或缩放，再只给模型10%的行。有效训练子集ID、选择规则与比例同时保存；计算学习曲线时也遵守该规则。

默认训练使用划分得到的全部训练数据。只有学生主动开启数据量实验时才填写训练池使用比例，避免隐藏的再次减半。

### 8.3 测试集使用记录

验证用于选参，测试在锁定配置后评估。[S3] 最终评估前显示封存箱；评估时将结果关联配置、样本角色、数据来源版本和依赖版本。

接触记录从第一次拟合/诊断就开始，分别记录哪些源样本参与过处理器/模型拟合、验证选参或逐行目标/误差诊断，以及哪些测试指标已经展示。旧训练或验证样本重划入测试时，即使从未调用过最终评估接口，也不能标成未参与学习的测试样本。

首次训练后，默认继续保留原测试角色；学生仍可选择“自由重划分”，但系统要检查新测试群体与上述接触记录的交集。存在交集或已经看过测试指标时，允许做探索性重评，并如实标记；不能作为本任务的独立留出成绩。若需要保持独立评估，应继续用保留的测试群体，或采用真正未参与本任务学习的新数据，而不是清空记录。

接触状态由服务端按源数据/实体/样本标识持久化，派生清洗版本继承来源。这里的“独立”限定本平台记录的训练和选参流程；“封存”不是把公开数据变成不可查看的秘密。

## 9. 参数页：有参数清单，核心数值留白

### 9.1 基本交互

- 入门页只展开1～3项核心设置；数值框为空，枚举显示“请选择”。“含义/范围/示例”放在可点击、可聚焦的问号内。
- 核心设置未完成时不能训练；高级参数按需启用，启用后的字段也要填写。
- 未启用的高级项使用明确可查看的模型模板，不偷偷把空字段转成0或随机默认值。训练前展示最终生效配置，包括库默认项及来源。
- 学生需要示例时可打开参考；“采用示例”必须由学生主动点击，并保留辅助标记。示例不是加载页面就自动填好的答案。
- 支持科学计数法；空字符串和输入中的`-`、`1e`等暂态保留为未完成，不能经`Number("")`转成0。超界时保留输入并提示，不静默夹到边界。
- 一次成功训练后，可为已填写的数值启用同步滑块。再次修改形成新草稿；只有重新训练后才显示该配置的新结果。

### 9.2 拟采用的核心范围

以下是产品拟采用的课堂计算范围；当前0.16尚未提供这套空白表单。实际接口与本地锁定的scikit-learn 1.9.0核对后再实现。

| 模型 | 核心字段及范围 | 高级项举例 |
|---|---|---|
| 逻辑回归 | C：0.001～1000；最大迭代：50～2000 | 类别权重；求解器/正则组合须做兼容校验 |
| GaussianNB | 方差平滑：1e-12～1e-2 | 类先验，初期采用明确模板 |
| KNN分类 | K：1～51整数；均匀/距离加权 | 欧氏/曼哈顿距离 |
| RBF SVC | C：0.001～1000；γ：1e-5～100 | 类别权重，校准另作进阶 |
| 决策树分类 | 深度：1～20；叶节点最少样本：1～50 | 分裂指标 |
| 随机森林分类 | 树数：10～200；深度：1～20；叶节点样本：1～50 | 每次分裂使用的特征数量 |
| 普通线性回归 | 是否拟合截距：待选择 | 正约束后续开放；不虚构学习率或训练轮数 |
| 岭回归 | α：1e-6～1000；是否拟合截距：待选择 | 求解器初期固定可复现方案 |
| KNN回归 | K：1～51整数；均匀/距离加权 | 距离度量 |
| RBF SVR | C：0.001～1000；γ：1e-5～100；ε填写范围见下文 | 核类型后续开放 |
| 决策树回归 | 深度：1～20；叶节点最少样本：1～50 | 回归分裂指标 |
| 随机森林回归 | 树数：10～200；深度：1～20；叶节点样本：1～50 | 特征抽样比例 |

SVR的ε对应目标尺度，不能当作无单位的分类参数。[S5] 初期在目标原始单位下填写ε：Wine的ε允许0～3分，Auto的ε允许0～10 mpg，Concrete的ε允许0～20 MPa；这是ε参数的课堂范围。新增数据须先配置单位和范围。后续若开放目标缩放，要明确ε在什么尺度上生效，并把预测变回原单位。

### 9.3 动态限制与真实影响

K必须不大于当前有效训练样本数；存在内部重采样时还要检查实际拟合子集。树的叶样本设置、分类类别覆盖、模型需要的数值类型都在训练前校验。solver/正则等组合只开放兼容项。

参数帮助不许诺“数值越大越好”：小K可能追随局部噪声，深树可能增加泛化差距，较强正则可能使模型过于简单，更多树可能增加耗时而不改善验证指标。系统实际跑出支持、反例或近似无变化，都应如实展示。

## 10. 训练结果：按任务与模型展示真实证据

### 10.1 分类结果

基本视图：训练/验证准确率、平衡准确率、Macro-F1、混淆矩阵、逐点真实类别与预测、错误类型定位。二分类在任务定义中明确正类、源标签映射和评分方向，并在图例/运行快照保存；然后开放Precision/Recall、ROC/PR和阈值探究。多分类按类展开，不能只展示二分类式指标。

连续二维边界只用于两个数值输入；网格和样本都经过同一个训练内拟合的处理链。坐标使用原始值时标原单位，采用标准化值时明确标注。涉及类别输入时展示合法类别组合的预测网格，不在类别编码之间插入虚构的连续类别。

多特征模式优先展示混淆矩阵、错误样本、特征关系；二维条件切片必须说明其余特征固定为训练中位数/众数或学生明确选择的值。PCA/t-SNE散点投影不能被称为完整模型的原空间决策边界。

阈值探究在训练后主动开启，输入初始留白；未开启时使用模型自身的预测规则并在配置里说明。概率估计阈值为0～1；SVM决策分数不能冒充概率，初期保留其0分数阈值，概率校准留到后续。[S9] 评分方向必须对应所选正类。缺少计算条件的指标显示不可计算及原因，不填造0或100%。

### 10.2 回归结果

提供训练/验证RMSE、MAE、R²、真实值—预测值对照、残差与样本定位、模型对照、学习曲线和参数复杂度扫描。

一维机制课保留真实拟合曲线；多特征回归用预测对照及明确条件切片表达。学习曲线通过多次真实拟合不同训练子集得到，不伪装成Ridge或决策树的逐epoch损失。R²允许为负；目标方差为0等不可定义情况说明原因。

不默认画未经计算的置信带。多次种子结果先按已有方式报告描述性均值/样本标准差；后续区间估计另做方法与计算。

### 10.3 机制视图随模型变化

树模型展示真实树路径；KNN展示真实邻居；线性模型展示实际系数；森林展示实际单树输出和集成输出；SVM展示合法边界/评分。相应模型的后台没有逐轮接口时，前端不编造训练曲线或进度百分比。

## 11. 选择影响面板与可比性

每次运行生成“这次改变了什么”清单：清洗、特征、样本、划分、模型、参数、决策阈值。学生可以定格A，创建B。

| 学生的改变 | 应当看到的反馈 |
|---|---|
| 中位数改均值 | 填补统计及处理行变化、同一评估集下的指标变化 |
| 缩放方式改变 | 特征分布/距离变化、实际边界/预测变化；不保证所有模型都明显改变 |
| 树深改变 | 真实树结构/复杂度、训练和验证误差变化 |
| α改变 | 系数、预测曲线/残差、验证表现 |
| K改变 | 被采用的邻居和投票/平均、当前预测 |
| 训练池使用比例改变 | 训练条数、固定评估集上的学习曲线 |
| 三份划分或种子改变 | 实际样本身份/类别分布、评估群体变化提示 |
| 二分类阈值改变 | 使用同一批模型输出重算混淆矩阵/Precision/Recall，不假称重新训练 |

同一评估样本、相同指标与单位下才做直接胜负比较。验证群体不同可以并列观察，但不把差异全归因到某个超参数。一次改变多项时给出完整差异，不编造单一因果解释。

支持“恢复A，只应用这一项变更”准备受控实验。结果变化是本次固定条件下的证据，不自动推广为所有数据都成立。

## 15. 工程改造规格

### 15.1 沿用技术基础

继续采用Next.js/React/TypeScript、FastAPI、NumPy、scikit-learn、SQLite与当前Python 3.13环境。解释性主图继续采用SVG/Canvas。在线文档目前为1.9.1，项目锁定1.9.0；实施时核对本地接口，不在重定位中顺便自动升级依赖。

### 15.4 状态与失效规则

| 改动 | 需要失效/重算的内容 |
|---|---|
| 数据/目标/特征/清洗/划分/模型/训练参数变化 | 当前训练结果与解释，形成新运行 |
| 只改图的显示特征、探针、缩放 | 只改视图，不能声称模型重训 |
| 改合法决策阈值 | 用原模型输出重算分类决策/指标，保留同一拟合模型 |
| 结果已提交后迟到的旧请求 | 不覆盖新配置，按所属运行保存或丢弃视图应用 |
| 测试结果已查看后继续探索 | 保留来源级测试接触状态 |

草稿使用空值/原始输入字符串，成功校验后才规范化成数值。旧结果可作A保留，但必须标为上次运行，不能随新输入伪装成最新结果。

### 15.5 预算与错误反馈

初版目标为小规模CPU表格任务，建议课堂数据上限5,000行、50个原始特征，展开后特征另设上限；森林最多200棵。单次运行设置约30秒预算并记录超时/取消状态，超时不伪装训练完成。复杂模型在预览阶段提示成本。

不收敛、类别不足、缺失未处理、参数不兼容、空特征、指标不可定义等分别反馈。输入错误定位到字段；训练警告保留实际结果状态与原因，不能静默当作完全正常的结果。

该阶段先完成新品牌、导航和模型参数规范，再实现流水线及表单。当前已知比赛截止为11月18日15:00；若维持该截止，这个切片是优先演示目标，需以验收决定冻结范围，不承诺在剩余时间完成全部平台。已有稳定版本和历史保留，不制作提交材料。

### 阶段B：统一当前8个模型

将现有KNN、SVM、森林等计算接入统一流程，完善概率/评分能力差异、数据处理、空白输入、比较状态与响应式。模型图鉴只把真正可用的完整课例列为可训练。

### 阶段C：扩展到12个模型与新增课例

新增GaussianNB、普通线性回归、KNN回归、SVR；接入Penguins和Banknote，恢复Auto原始缺失版本。让新增数据各自承担明确课程目标，完善自然缺失、类别变量和二分类错误分析。

### 阶段D：深化内容与进阶

增加Lasso/ElasticNet/梯度提升、多目标与时间顺序课例；补完整模型机制图、适量新Q版素材和CSV导入。CSV导入需有大小/类型/列数限制、目标选择、敏感列排除和版本化，不能假装所有表格都适合所有模型。

粗略工作量：A约2～3个专注开发日，B约1～2日，C约2～3日，D按模块另排；这不是完成承诺。个人AI辅助开发也先保证一条完整流程和验收，再扩数量。若A超过截止窗口，先保留已验证软件范围，完整定位按后续阶段继续实现。

## 17. 验收清单

| 范围 | 可判定的完成标准 |
|---|---|
| 命名与导航 | 名称、页面标题、入口和帮助一致；历史来源保留，现有记录可打开 |
| 任务理解 | 能区分类别标签与连续预测；不支持的任务/模型组合不会被错误训练 |
| 空白参数 | 首次核心值为空；空不变0；非法数值不自动夹边；无缺项偷用默认值 |
| 合法性 | 比例和100%、样本/类别覆盖、K与训练量、参数组合、单位约束通过前后端检查 |
| 处理顺序 | 自动测试证明填补、缩放、编码只拟合训练；CV每折独立拟合 |
| 数据身份 | 原始快照不被改写；重复实体不跨集合；目标/实际划分数量可核对；每个训练子集独立拟合完整流水线 |
| 训练执行 | 每个首期模型使用学生值；警告、取消、超时与成功状态准确 |
| 指标 | 分类/回归指标分别校验，R²负值、不可定义指标与平局如实处理 |
| 可视化 | 决策边界/条件切片、系数、邻居、树路径、残差对应真实计算 |
| 对照 | 同条件可比、不同评估样本不误排名；多变量变化不编造单因果结论 |
| 测试 | 拟合/验证/诊断/测试接触状态持久化；旧训练或验证行改入测试也不会被当成独立留出 |
| 学习记录 | 首次判断不被重做覆盖；示例/AI辅助单独标记；旧课程不虚增新进度 |
| UI | 1366×768、1440×900、390×844可完成流程；主控件可发现，无拥挤、溢出及过小目标 |
| 恢复 | 刷新、前后步骤、配置变更、历史版本、备份重算均保持正确关联 |
| 复现 | 新环境可启动核心流程；运行配置、依赖与数据版本齐备；记录真实Git/AI过程 |

学生试用可另作为后续教学研究，本方案的完成验收不以此为条件。

## 18. 查阅依据
