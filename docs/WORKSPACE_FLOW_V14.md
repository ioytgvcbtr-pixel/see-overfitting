# 0.14 · 从启动到下次继续

## 本轮范围

启动自检与复用实例、AI设置和主动连接测试、首页统一继续、课程/四岛/AI统一档案、准确中途续接、针对误区复练，以及版本化学习备份和恢复。保留既有数值约束、首次作答、xhigh、Git与脱敏AI过程；提交视频/PDF继续暂缓。

## 实现约定

- 启动脚本检查解释器、Node、依赖与数据快照，提供中文修复方向。识别已有FitLab而非关闭占用端口的其他程序；支持独立端口和无浏览器验收。默认继续使用本地配置的Python。
- 设置只返回非敏感配置与密钥是否存在。空密钥输入保留原配置，开关可使用规则讲解；思考强度保持xhigh。主动连接测试才调用模型，状态区分配置、测试结果和本次降级。测试响应不显示推理或凭据。
- 统一档案读取已有SQLite记录，不合并不同任务的分数；课程完成数、四岛学习轮次和需复盘数量各有含义。首页从服务端找到最近未完成学习，旧自由观察续接仍可用。
- 四岛草稿保存当前输入、选点和未提交选择；浏览器有界草稿兜底，服务端阶段校验防止迟到保存覆盖已提交答案。恢复时重新计算，保留首次作答；参数与成绩不混存为可信证据。
- 错题复练关联原记录，使用本轮和迁移之外的种子；有限题库重复时说明。原错答不改写。
- 备份只包含学习、实验与AI记录，排除模型密钥和配置。导入先校验/预览、复算数值与判定，已有首答不覆盖，导入来源可见；原课程和四岛恢复入口可从数据库重建。

## 界面

沿用紫/青/暖色语义、系统中文字体、tabular-nums与柔和阴影。首页以开始/继续/探索组织；设置单独一页，模型高级项与备份详情按需展开。档案用行式列表，操作至少44px，避免重复卡片和小图标。学生看到能否继续与恢复动作；解释器和端口信息留在启动诊断。

## 验收

先协议与数据测试，再前端、类型及生产构建。测试单变量操作中途参数和选点/迁移草稿恢复、清理浏览器后的服务端入口、首答不覆盖、AI连接真实/失败状态、备份往返及篡改指标重算。Chrome使用独立端口和数据库进行写入验收，保留原3/3工作区；检查五档布局、恢复正常视口并保留实机截图。
