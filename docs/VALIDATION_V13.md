# 0.13实际验收 · 四岛学习、反例与AI操作

2026-11-15。开发验收在Chrome的localhost来源进行，原127.0.0.1工作区最终核对仍为3/3。新版在Chrome保留了原工作区与独立演示页，临时视口/媒体模拟已恢复。全程未提交原课程的新预测或迁移答案。

## 学习协议与数值

四岛均在实际界面完成预测、手动调参、观察核验、新种子迁移及依据提交。预测和迁移未提交时，学习接口不返回本题指标、正确选项或正确依据；任务的目标参数本身会公开，便于操作。首次预测/迁移不可覆盖，同题重复请求幂等；改变固定条件或未达到目标会拒绝观察。数值由既有概念/分类引擎复算，测试封存。

| 反例 | 实际条件与结果 |
|---|---|
| 误差湖 | seed314，截距−0.3→−0.4：训练MSE 0.4804→0.4699，验证0.5414→0.5744；先猜“降低”的错误保留 |
| 曲线山 | seed314、B15阶、α0.01、点7移动到−0.69：A/B RMS 0.0376/0.3044，验证MSE 0.0717/0.0672；变化更大与预测误差更高没有被混为一谈 |
| 约束花园 | seed314、12阶、α0.01→100：范数0.9592→0.0706，验证MSE 0.1045→0.4660；迁移到seed2026的0.01→0.1，验证0.0685→0.0626 |
| 边界森林 | seed43的XOR，SVM→逻辑回归救回点55，但整体验证86.7%→51.7%、错分8→29；迁移到seed42的逻辑回归→SVM，验证61.7%→96.7%、错分23→2 |

曲线山反例在限定候选中要求B的RMS至少增大10%，且验证MSE至少低5%。三个允许种子均通过数值条件测试。最初选用的微小RMS差异实例被替换；初版迁移核验仍比较RMS的错误由完整流程测试发现，已改为按题目所问指标判定。

## 真实AI操作

误差湖观察后，DeepSeek Flash以online模式生成“截距−0.4→−0.5”的单变量方案，预期为只观察、不预设方向。实际执行后，验证MSE 0.5744→0.6274，记录为已观察变化。刷新、回看后仍能看到模型来源、原假设及执行证据；恢复执行前条件不改写原结果。

请求继续使用reasoning_effort=xhigh、thinking启用；兼容映射native high。没有输出模型推理正文。单元测试覆盖四岛的合法候选、独立复算、过期参数拒绝、执行幂等、迁移期间暂停AI及非法候选明确降级为规则方案。结果支持、不支持与只观察分别呈现；没有假称所有方案都改善模型。

## 恢复、提示与反馈

- 四岛记录存本机SQLite，浏览器仅保存ID。刷新后显式继续或回看，不让旧学习任务接管自由输入。
- 曲线山另做一次错误预测，使用两级提示及“按提示设置目标”；迁移故意选错。刷新后保留原预测、信心、初次错答、提示2级和辅助标记，界面显示仍需练习。
- 完成页可展开原预测与实验，分别复现原实验和迁移场景。已核验成功/失败恢复时animation=none，不重播回应。
- 因果回放实际记录B阶数12→13，对应RMS 0.0474→0.0524。只在输入与实算匹配时更新；减少动效模拟下，回放animation与物件transition均为none，随后恢复默认媒体设置。
- 花园学习起点使用实际系数建立线性放大窗口，调α保持窗口，超窗↑明确；例如恢复α0.1时可见的六根茎高度约4～44个SVG单位，不再因弱约束的巨大系数完全压扁。
- 原课程保持3/3；四岛不改原成绩。提示或迁移前AI使用标为有辅助，不将其记为无辅助作答。

## 布局与可见控件

误差湖、曲线山、花园、森林，分别检查预测/完成两种状态及320/390/768/1024/1440px，共40组。页面clientWidth分别305/375/753/1009/1425，scrollWidth相同。可见主要按钮、滑块、选择器及森林门/包裹均至少44px，没有发现相互重叠。额外核对390px完成反馈、1440px展开复盘及历史。

初次测量把关闭details中的几何框算作可见，且在ResizeObserver重排前读取SVG，产生误报；改为排除折叠区域并在绘制后测量。实际发现历史“回看”按钮宽38px，修到44px后复测。森林模型控件被折入旧任务，已移到场景下方。手机长按钮出现末字单独换行，缩短为“查看场景”并调整局部内边距。

场景与控件相邻，学习区每次显示当前步骤；AI、历史、原实验及自由观察按需展开。进入新学习会暂存旧自由观察，避免后台草稿继续跟随新任务改写。已有同心圆角、稳定数字、均衡标题、柔和阴影和分组入场保持。

## 自动检查与边界

96项Python（新增21项）、32项前端逻辑（新增3项）、类型与生产构建通过。Python仅有既有Starlette/httpx弃用警告。浏览器应用error日志为空。没有新增运行时依赖或图像素材。
