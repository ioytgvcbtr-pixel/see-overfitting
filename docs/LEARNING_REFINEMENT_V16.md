# 0.16 实施计划

1. 新题使用v3协议：判断先锁定，再选择依据；答案键和依据在判断前不返回。旧题按原协议继续恢复，不重写成绩。模型选择采用实算候选、不同噪声情境和确定性位置平衡；对平局进行显式校验。
2. 花园保留全量范数参照，枝条默认采用明确标注、固定的局部刻度。小到不可辨时提供放大入口，调整刻度有提示。主画面并排展示系数与真实曲线，可选枝条贡献、移动验证探针查看预测/观测/残差；所有数值由后端计算。
3. α主控件与关键读数移到画布上方，阶数等条件折叠；短屏收拢重复页头，窄屏自然排列。延续紫色主色、绿色数据、橙色验证与现有中文字体、tabular-nums、44px目标、柔和阴影与留白。新增图形是科学证据，不增加装饰卡片。
4. AI操作实算后，完成原迁移的记录可以一键进入针对性新情境。新验证单独保存，带来源/辅助标记，原题首答保持；中断与备份均可恢复。

验证覆盖位置分布、实算候选、判断锁定、提前提示、旧版兼容、备份、贡献项加和、探针读数和AI后续来源。运行全量核心检查、生产构建、Windows CI和Chrome桌面/窄屏关键流程。主工作区与API配置保留；写入验收使用隔离数据库。不制作提交视频或PDF。
