# 0.12 · 挑战续接、分层提示与向导回应

用户要求完成上一轮三项建议，并检查图标过小、元素拥挤，适度增加角色与小元素。沿用0.11等宽数字、同心圆角、100ms分组入场、均衡标题与柔和阴影。

## 实现范围

1. 四岛挑战保存参数、原实验、作答、核验动作与提示层级。浏览器仅保留有界草稿，不保存可信成绩；刷新/返回时分别复算起点与当前结果，再决定核验状态。支持暂存、继续和重新开始，首页提供最近挑战入口。
2. 错答后先定位图上的证据，再按需展开关键数值。未实算时暂停提示核验；条件变化清除旧选择和提示。森林区分猜中模型与真实分类，保留同条件救援的整体指标。
3. 用现有Q版向导衍生思考、庆祝姿态；由实际核验状态驱动，短动作可关闭并尊重减少动态效果。角色不遮挡画布或控件。

## 布局选择

角色固定独立占位，桌面约96px、手机约80px；帮助/按钮图标统一20～24px，点击目标至少44px。反馈采用一个清晰区域；场景数据、控件、提示与角色有各自空间，不以大量小徽章装饰。移动端顺序为场景、实算读数、操作、挑战反馈。读数固定网格；加入RMS数值时使用两列配对布局。

新增图案只用于继续、定位、发现和角色回应。生成素材是固定透明PNG，科学图形仍来自数值后端。完整提示词与用途保留在public/illustrations下。

## 验收

验证刷新/离开后续接、暂存后的自由探索、旧答案重算、错误与网络失败、条件失效、两级提示定位、角色状态和动效开关。检查320/390/768/1024/1440px、浮层避让、图标目标、按钮换行与图形裁切。保持原正式学习记录，不制作比赛提交材料。继续真实Git与脱敏AI过程。
