# 0.13 · 四岛的预测、实验与迁移

## 本轮范围

先建立四岛共用的服务端学习状态机，再实现反例挑战与岛内单变量AI操作，最后补首次引导和因果表达。延续0.12视觉和独立自由探索，不制作竞赛视频、PDF等提交材料。

## 学习协议

- 服务端提供有界任务描述、起点/目标参数及预测选项，不返回结果或正确答案。首次预测、信心与可选理由提交后锁定，SQLite保存。
- 学生调节现有滑块/训练点到目标条件，再提交实验。服务端验证输入、独立计算前后结果，保留数据指纹、原预测和真实证据。
- 迁移使用另一随机种子，提交判断和依据后才揭示真实比较。首次作答保留，同题重复请求幂等；错答后可以创建新的练习，提示或AI辅助单独标记，不混同独立完成。
- 每岛均有常规和反例任务。反例从限定候选中用真实数值筛选，找不到时明确失败，不编造结论；题目与迁移答案不进入公开预测响应。
- 旧课程3/3与四岛学习分开，统一面板可回看四岛记录，浏览器只记服务端ID。自由观察旧草稿继续有效。

## AI操作

复用coach.suggest的JSON候选约束、xhigh和真实降级提示。只在已完成观察后开放AI探索，避免提前泄露预测或迁移答案。先提供当前参数与合法单变量候选，展示原值、目标值及待验证假设；用户执行后后端重算、校验指纹并存证，允许不支持预期。输入变化使旧方案失效。操作不改写已保存学习证据，不执行AI生成代码。

## 视觉与交互

每次只显示预测、实验、复盘、迁移中的当前内容。角色沿用独立占位；初次引导可跳过，说明放在问号/折叠区。旧自由观察与可选AI工具折叠，避免任务叠放。主要触控目标44px，图标20px以上，读数tabular-nums，标题均衡换行，柔和阴影与同心圆角保持。

因果反馈从实际输入变化与后端匹配状态触发：当前物件、对应证据和变化说明相邻，保留前后对照。新结果匹配后才强调，恢复不重播，减少动态效果关闭动画；提示不以颜色作为唯一编码。

## 实施与验收顺序

1. 四岛数值任务、预测门禁、持久化、真实观察、迁移核验与反例筛选测试。
2. 共用前端学习面板、可选AI候选/执行、独立学习记录与恢复。
3. 首次引导、因果强调、手机/桌面留白和布局。
4. Python/前端逻辑、类型、生产构建及Chrome完整流程，保留实机截图、真实Git和脱敏AI记录。

重点检查预测/迁移未提交不泄露结果、过期参数拒绝、重复请求不重复计次、错误首答不覆盖、规则降级可见、原学习状态保留，以及320/390/768/1024/1440px下目标尺寸、重叠和溢出。
