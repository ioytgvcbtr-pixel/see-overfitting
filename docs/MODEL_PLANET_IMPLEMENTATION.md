## 已发现并修正的问题

同种子参数对照一度只冻结测试集，验证身份仍会改变，已改为同时冻结训练/验证/测试；AI候选预检读取持久化数组时需恢复数值类型，已修正。迁移改种子时继续保留原测试角色，恢复后使用同一锚点复算；原首答和实算观测相等已有回归覆盖。参数枚举的原生字符串/布尔/空值与前端选项统一；切换样本或目标清除旧解释。图坐标刻度与实际映射统一，标题从旧全局flex样式中隔离，避免词组被拆开。

新增数据分别承担自然缺失/类别处理、二分类错误分析、多目标与时间顺序的教学任务。模型数量不代替教学闭环，所有结果视图关联所属运行快照。
