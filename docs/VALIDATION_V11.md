## 五项实际核对

| 要求 | 实测与实现 |
|---|---|
| 稳定数字 | DOM计算样式为lining-nums tabular-nums；浮标0.0263→−3.0000、平方项2.1391→20.1497时，六个数值槽位的x位置和宽度保持不变；当次窗口每槽宽330.667px |
| 同心圆角 | 桌面外40px、内20px、内边距20px；390px下外28px、内16px、内边距12px。课程封面贴边时沿用父级顶角 |
| 100ms淡入 | 标题组0s、主题组0.1s、数据栏0.2s、舞台0.3s。只改变opacity，调参不修改动画属性。通过浏览器模拟减少动效后animation=none、delay=0s，已恢复默认媒体设置 |
| 标题均衡 | h1实测text-wrap=balance，长场景标题改为短而具体的对象名称；40种布局中无页面横向溢出 |
| 柔和阴影 | 舞台边框0px、三层阴影，主要透明度约0.025/0.035/0.025。保留表单、选中状态和焦点的功能辨识 |

固定槽位像素值只描述当次桌面视口，不是各尺寸的固定屏幕坐标。次级文字/白5.85:1，问号/白4.01:1，输入边界/白3.57:1；选择轮廓与三种选中底色3.32～3.57:1。此为所选颜色对检查，不是完整无障碍认证。

## 问号浮层

- 键盘Enter打开、Esc关闭；悬停可打开，指针移入浮层后仍可阅读。
- 点击外部关闭，手机宽度点击打开，再次点击关闭。
- 浮层在顶层显示；390px内容宽375时左右59～359，320px内容宽305时16～289，保留16px安全边距。
- 真实数据页指标词典实测圆角24、边框0、内边距20，未继承旧details的硬边框。
- 首页切换预览后，浮层标题与三步操作更新，列表为纵向block，位置保持在视口内。
- 场景读法、比较范围、数据条件与复现信息按需打开；当前任务目标、更新状态、实算值和错误反馈直接可见。

## 自查修正

原浮层采用innerWidth，滚动条占宽后边距不足；改用documentElement内容视口。旧指标说明选择器覆盖了浮层样式，增加针对性规则；首页操作列表继承横排，改为纵排。截图自查发现sr-only原来只有工坊作用域，补全通用工具类后，四段首页辅助描述为1×1、absolute、inset(50%)，不占视觉排版，仍供描述关系读取。未以隐藏说明替代必要的错误或计算状态。
