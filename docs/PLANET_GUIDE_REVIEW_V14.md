# 模力星球1.4整体流程与视觉复核

## 角色与动作

小模采用有表情的学习星球：球体、前后分层星环、卫星、星光与夜间表情。共享一个中心坐标与运动时钟，卫星按椭圆连续绕行并在球体前后正确遮挡；动作切换平滑改变速度，不让星体和轨道各自跳动。待机微浮/眨眼，招呼点亮星环，思考卫星巡航，轻触回应/投喂星光/卫星绕行。减少动效和后台标签页停止帧循环，互动不计学习分。

实验提示、继续挑战和机制反馈复用同一星球形象；静态提示不播放待机。原场景插画保留为环境，不再称作“小模”。设置预览去除额外的大椭圆，避免视觉上出现两个轨道中心。

## 整体评审与本轮改进

| 环节 | 现有问题及证据 | 实施方向 |
|---|---|---|
| 继续学习 | 服务端resume_id总取最后打开课，已完成后仍可能继续同一课 | 优先最近未完成，再下一未完成；全部完成进入复习 |
| 知识→实践→回看 | practice跳入数据或机制，但没有保留来源课题的显式返回入口 | 保留课题实践上下文，提供回原课与退出实践入口，不自动授课完成 |
| 数据任务 | 11个课例展示缺少任务子类型筛选 | 分类按二分类/多分类/多标签；回归按单目标/多目标/时间顺序筛选，并显示类型 |
| 模型图鉴 | 17条只分分类/回归，查找特定模型需滚动 | 增加模型/关键词检索及明确空结果恢复 |
| 训练→结果 | 完成提示只有状态，真实结果可能在首屏下方 | 增加查看已完成结果入口；不把新草稿当成新结果 |
| 记录回看 | 运行时间线有数据与状态，模型身份不够直观 | 服务端返回真实模型标识，界面显示模型名；失败/取消明确重试入口 |
| 导航命名 | 全站学习航线和机制内旧学习路径容易混淆 | 机制内使用“基础实验课”，18课航线保持原名称 |

整体保留：独立设置、DeepSeek官方调用与自选深度、18格/4格独立进度、真实数值与封存测试、原始首答、档案兼容、个人配色与阅读偏好。不新增上传训练或准备提交材料。

本轮用代码原生SVG以保证轨道、表情和遮挡可控；继续沿用已有Q版星球场景资产。所有决定从学生能否找到下一步、看懂当前证据和回到学习内容出发，不以装饰数量或动画幅度作为完成标准。
