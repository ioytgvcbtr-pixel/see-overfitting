# v0.15 教学质量与验证计划

## 本轮目标

先修正迁移题的可判断性，再把约束花园做成一段有自主选择的学习体验。预测允许未知，迁移必须给足观测证据；首次回答、提示、AI辅助和复练分别留存。旧记录按原题意恢复，不重写旧成绩。

1. 四岛迁移提供后端实算的观测图与数值表。理由改为同一情境下的可信干扰项，避免靠绝对化措辞猜答案。
2. 花园提供读证据、选择模型、设计控制实验三种迁移表达。新题版本化，导入时重算题目、数据和评分。
3. 花园增加自主反例：学生锁定第一次α及预测，只改变α，逐次核验“系数收缩但验证误差升高”。失败尝试也是记录；完成标准由后端判断。首次预测对应第一次操作，不能拿后来找到的反例倒算预测。
4. AI接收已提交的判断与依据，给出待检验的错因线索和合法单变量方案。预期不确定只记观察；方向性预期才核验支持或不支持。未答迁移期间保持独立作答。
5. 增加关键浏览器回归、Windows CI、数值接口性能测量，记录实际运行结果。后续质量改进与评分以REVIEW_V15.md为准。

## 界面约束

保留岛屿与角色语言。主画布仍是实验中心，侧栏按阶段只展示当前任务。观测图使用蓝色训练数据、橙色验证数据、青绿色系数/扰动，并辅以文字和数值，避免只靠颜色。沿用现有中文无衬线字体，数字tabular-nums；标题均衡换行，按钮至少44px。图表占整行，细节表折叠；窄屏改为单列。不增加新的页面装饰卡片。

## 验收

- 新题可凭提供的真实证据作答，答案键未提前发送；三个种子均复算。
- 自主反例拒绝改变样本、噪声、阶数等混杂条件；保留失败试验和第一次预测；刷新与备份可恢复。
- AI收到实际错答依据，生成、执行、复算及辅助标记可核对。
- 原课程成绩和v0.14历史兼容；离线核心可使用；桌面/窄屏无横向溢出。
- Python、前端逻辑、类型、生产构建及关键浏览器流程通过，测量与人工试用分开报告。
