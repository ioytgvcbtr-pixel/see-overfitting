# 看见过拟合：功能与交互设计 v1

创建日期：2026-11-12（Asia/Shanghai）。目标：AI创新应用挑战赛，研究生组、个人赛。省赛最终截止：2026-11-18 15:00。

## 1. 用户与价值

面向初学机器学习的大学生及研究生，用一次可复现的交互实验理解欠拟合、过拟合和正则化。用户先预测，再操作、比较、解释、练习，最终保存一份带参数、指标和结论的实验报告。

学习目标：区分训练误差与泛化误差；理解复杂度和样本量影响；学会用验证集选择参数，最终独立测试只用于最后评估。

## 2. 页面与视觉

桌面工作台：左侧固定课程导航；顶栏显示当前工作区、AI连接状态和报告入口；主区域依次呈现课程标题、指标卡、拟合画布与参数面板、实验记录与解释教练。另有学习路径、实验档案视图。

设计语言：暖白背景、深墨文字、靛蓝主色、青绿训练点、珊瑚色验证点；细边框和轻阴影；等宽数字；留白稳定；控件有即时反馈。绘图使用代码原生SVG，保持清晰、可访问和导出一致性。移动端导航收起、画布与参数纵排；图表保留图例与坐标轴。

核心交互：滑块改变参数后短暂防抖请求，取消旧请求以避免结果覆盖；生成期间保留上一张图并说明正在计算；计算失败允许重试；API未连通时明确使用规则分析；按钮有禁用、进行中、完成、失败状态。

## 3. 省赛版本功能范围

### F1 三个实验场景

1. 模型复杂度：小样本含噪声曲线，多项式阶数1—15；观察训练/验证误差。
2. 样本与噪声：控制训练样本数量及噪声。样本量变化保持验证/测试的x和标签完全不变；噪声变化则在相同x和同一标准高斯噪声抽样上，为三组标签同时缩放噪声，观察数据生成条件变化。
3. 正则化：在15阶高复杂度模型下控制Ridge系数，观察平滑与误差权衡。

每个场景包含明确任务、推荐初始参数、一个预测问题、一条操作建议和一题迁移练习。场景切换重设参数、清除当前解释，但保留已保存记录。

### F2 数值实验

输入：scene、degree、samples、noise、alpha、seed。数据由固定种子生成；训练、验证和测试用独立随机流，保证可重复和互相独立。训练样本取同一训练池前N条，便于同源对比。

模型：PolynomialFeatures + StandardScaler + Ridge，所有拟合步骤仅接触训练集；真实函数为cos(1.5πx)。输出训练MSE、验证MSE、泛化差距、拟合曲线、训练/验证点、耗时、诊断及可追溯实验指纹。

图表显示训练/验证点、真实函数与拟合曲线；支持图例与悬停读数。所有点可在报告中复核。阶数扫描按需触发，用同一数据划分比较1—15阶。图轴裁切必须明确提示，避免隐藏极值。

### F3 预测、练习与进度

预测问题先选择再揭示解释；答案、正确反馈和学习说明固定且审校。迁移练习记入本地学习进度，保留重做。进度不伪装为研究性学习效果证据。

### F4 合成实验记录、比较与独立测试

记录保存在SQLite，包含参数、完整实验结果、预测、备注和时间。档案支持载入、最多三组对比；刷新后保留。独立测试需用户点击“最终评估”才计算和展示，结果说明不用于继续调参。任何参数变化、切场景或重新载入记录时，当前测试显示与AI解释清空；测试结果只进入当次导出的报告，不随档案永久保存。保存的结果包含数据指纹以便追溯。

### F5 证据约束AI教练

后端读取忽略的.env；前端不接触密钥。采用DeepSeek官方Flash当前别名，具体供应商返回在联调记录中保存。Prompt包含实验参数与实际指标，要求输出观察、解释和下一步实验，约束避免声称因果或保证某阶数最优。返回明确provider/model/mode。网络或鉴权失败使用确定性规则说明，同时公开提示原因。每次实验变化使上一份解释失效。

### F6 报告与复现

生成Markdown与JSON报告，包含参数、数据划分、指标、独立测试状态、记录对比、AI模式及来源。弹窗支持在线预览与复制，并提供标准HTTP附件链接；浏览器允许下载时保存附件。可打印页面生成PDF。报告不包含API密钥。提供Windows一键启动、环境检查、依赖锁和10分钟复现说明。

## 4. 架构与接口

前端：Next.js App Router、React、TypeScript、CSS、lucide-react，代码原生SVG绘图。后端：FastAPI、NumPy、scikit-learn、SQLite、httpx。Python从本地环境配置选择。Web请求通过Next.js `/api/...`转发至127.0.0.1:8000，浏览器只需同源地址。

- GET /health：版本与能力状态，不返回任何secret。
- POST /experiments/run：验证参数并执行实验。
- POST /experiments/sweep：同一数据的复杂度扫描。
- POST /experiments/final：独立测试评估。
- GET/POST /records：读取/保存实验。
- POST /coach：基于后端重新计算的实验解释，不信任客户端自报指标。
- POST /reports：服务端重新计算指标并生成报告快照；GET /reports/{id}.json或.md返回HTTP附件。

API错误返回用户可理解的消息；不回显密钥与供应商请求头。SQLite运行数据置于data/并忽略。

## 5. 数据与来源

核心数据是显式标记的合成数据，不声称真实调查。官方教学来源：https://scikit-learn.org/stable/auto_examples/model_selection/plot_underfitting_overfitting.html 。模型实现可复用成熟库，但应用交互与流程原创实现。

真实数据实验使用三份UCI公开快照，来源、CC BY 4.0许可、清理与校验值见data/public/README.md。具体功能和划分协议见第8节。

## 6. 验收标准

- 相同参数得到相同数据与指标；改变阶数/正则不改变数据划分；训练与验证测试独立。
- 三个场景均能完成操作、解释和练习；无需模型API即可运行实验核心。
- 改参时旧请求不覆盖新结果；保存/载入/对比/导出可用。
- 密钥不进入前端、仓库与过程记录；AI在线与规则分析可区分。
- 在桌面与390px宽屏完成主要操作，无水平溢出；键盘能控制参数与按钮。
- 后端数值/API测试通过；TypeScript与生产构建通过；浏览器人工流程核验并截图。

## 8. 0.2真实数据实验台

数据：UCI Wine Quality红葡萄酒1599条、Auto MPG392条（6条缺失马力记录已移除）、Concrete Compressive Strength1030条。CSV快照、来源、CC BY 4.0许可及原始/转换后SHA-256在data/public中维护。

模型：Ridge、DecisionTreeRegressor、60树RandomForestRegressor；另有训练均值基线。所有特征参与建模，汽车产地采用仅在训练集拟合的独热编码。

协议：先将完全相同的特征行作为一组，按组做60/20/20划分。训练池按固定顺序取10%—100%；改变模型、树深、正则或训练占比不会重抽验证与测试集合。预处理仅拟合当前训练子集。RMSE保留目标单位；R²允许为负，不做跨数据集原始误差排名。

展示：预测与真实对照、残差诊断、特征关系、学习曲线、模型对照、三种子稳定性复核。特征关系是观测散点，不作为偏依赖或因果效应。学习曲线固定模型参数与验证集合；对照显示所有模型配置；稳定性用配对种子并呈现每次结果和样本标准差，不当作置信区间。

可干预学习：一次只改变一个控件；收藏条件后可恢复重算。真实数据收藏保存在浏览器，最多12条。测试接触按数据集在本浏览器记录；改参和重划分不会清除已见提醒。该机制是教学交互记录，严格最终评价仍需独立新数据。

AI：请求reasoning_effort=xhigh并启用thinking；DeepSeek官方兼容映射为high。只返回最终解释和用量。解释证据由后端重算，包含适用参数、当前界面可用控件、已运行对照与复核。树模型不传入无关的岭回归α；已见测试的声明会进入解释和降级文本。

新增接口：GET /datasets；POST /bench/run、/bench/compare、/bench/learning、/bench/stability、/bench/final、/bench/coach。实现分别位于backend/datasets.py、bench.py、bench_api.py、coach.py；前端独立组件与SVG图表在DatasetLab.tsx和BenchCharts.tsx。

## 9. 0.3面向初学者的实验引导

主要用户：刚开始学习机器学习的大学生和研究生。设计问题是“先改什么、看什么、如何比较、怎样解释”，角色推演和公开页面观察不作为真实访谈证据。设计系统与外部参考在design-system/fitlab/MASTER.md。

基础课三步对照：复杂度1/4/15阶，样本量12/60/120，正则化1e-8/0.01/1。步骤只改变当前主变量；后端结果实际返回后才计入观察。对照键包含课程和其余固定条件，条件不匹配的旧结果不参与展示或最低验证误差判断。自由探索值仍可调节，但不计入推荐三步的完成数。

每课直接展示主要控件，其余控件放在“更多实验条件”。同一页面提供可展开的MSE/RMSE/R²解释和真实结果对照板。计算新条件时隐藏旧指标，标明暂保留的旧图形，并禁用依赖当前计算的操作。窄屏点击推荐条件直接定位图表；减少动态效果设置使用即时定位。

真实数据实验的下一步操作依次为模型对照、配对复核和基于证据的解释，六个展示方式保留。数据集选择紧凑，比较协议和指标说明可展开，测试接触状态保持原协议。模块导航使用可回退的地址片段；跳到内容链接只移动焦点。

视觉：清晰中文系统字体、浅蓝背景与白色科学画布；训练/验证点用圆形/方形双重编码，自适应SVG坐标和图表文字；焦点可见、主要目标至少44px，图标与字体不依赖远程资源。

## 10. 0.4预测先行与可执行实验

三个基础课程均先提交“预测哪组验证误差最低”、信心及可选理由，再请求与显示本轮结果。三步观察由后端实算留痕；比较结束后揭示预测是否匹配本轮最低验证误差。更改固定条件会隐藏旧结果，要求重新预测。

迁移使用新种子与另一组参数，显示实际训练/验证MSE；模型选择和依据均正确才计入完成。首次错答保留，同题不能改答案重复计次；重试生成新种子。SQLite保存全过程，浏览器保存当前课程与本轮ID，刷新可恢复；旧版静态练习进度不作为新闭环完成证据。

AI实验方案只从后端提供的合法候选中选择一个变量，界面先给出参数预览与可检验假设。用户点击后，服务端重算前后结果，比较实际验证误差方向与预期，呈现支持、不支持或只记录观察。方案条件不符拒绝执行，重复请求返回同一核验记录，不读取测试指标。真实数据的既有测试接触声明继续保留。

合成课与真实数据共用操作组件。执行档案、学习记录和功能报告均可保留实算证据，模型来源与规则降级明确区分。范围、接口和验收重点详见LEARNING_LOOP.md。

## 11. 0.5体验与学习复盘

学习档案分为学习足迹、AI核验、已保存实验。GET /learning/history提供最近50轮概要，不返回未提交题目答案。历史可继续或回看；POST /learning/attempts/{id}/practice生成未在已有学习及迁移记录中使用的种子，重新预测后才建立新轮次。旧判断不被覆盖。待预测条件以有界浏览器草稿保存，刷新仍使用新种子。

AI核验后可切换执行前后参数，原结论、指标和执行时间不被改写。功能报告按学习ID补回已执行的关联方案，避免刷新丢失临时ID后漏掉证据。真实数据记住数据集、模型、参数、视图、特征与训练样本展示选择；恢复后重算基础预测，比较及配对复核仍按需发起。

界面采用状态驱动的曲线航线、开放式预测、指标带、连续绘图区和行式记录。颜色由语义变量统一，训练圆点青色、验证方块橙色、模型线紫色。功能样式后加载产品视觉覆盖，规则见design-system/fitlab/pages/observatory.md。
