# 模力星球1.3：独立设置与小模宠物

设置独立为统一课堂视图`#classroom/settings`。旧settings哈希统一定位，不再进入机制工坊；设置显示自己的导航当前位置，可返回原学习页。配置分DeepSeek连接、学习问答与阅读、陪伴动作和记录入口。

仅支持DeepSeek官方HTTPS地址及当前Flash/Pro模型；固定服务商，密钥只写不回显，留空保留，可替换/移除。思考可选none/low/high/max，保留现有xhigh兼容选项（实际high）。密钥、模型、思考强度变化后连接状态失效，测试和实际请求使用同一配置。进阶可调超时与输出上限，默认保留原设置。

小模为原创代码SVG的Q版猫咪宇航员，头盔、耳朵、四肢和轨道可分层动画；与现有Q版星球统一颜色。桌面入口放侧栏底部预留空间，手机入口融入顶部栏，不常驻遮住实验图。待机呼吸/眨眼/轻浮，问候挥手、思考、开心、睡眠；摸头、投喂星星、绕轨道是明确按钮，不制造学习得分。

点击小模打开问答。可结合当前已公开课题、实验配置和验证指标；不发送原始数据行/未揭示测试，不泄露未提交检查的答案。只输出最终回答和实际模式/用量，网络失败明确本地提示。对话保存本机SQLite，可关闭保存、清空和新开对话；聊天本身不改变知识进度或自动执行实验。跳转练习要学生主动点击。

支持宠物开关、安静陪伴、减少动效、字号和上下文共享开关，个人偏好保存在本机；关闭宠物后设置可重新开启。问答支持取消等待、重试，不由迟到回答覆盖新会话；聊天抽屉手机单列、输入始终可用、Escape关闭并返回焦点。

官方核对：2026-11-16，api-docs.deepseek.com/guides/thinking_mode、api/create-chat-completion、api/list-models、quick_start/pricing。内置数值训练、学习首答和原档案保持原协议，本轮不准备提交材料。
