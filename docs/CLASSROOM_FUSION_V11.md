# 模力星球1.1：统一课堂与场景配色

学生在同一导航框架完成“理解机制→真实数据实验→返回证据”。机制工坊成为一级学习入口，保留原四岛、基础课、首答与档案；旧地址也进入统一界面。任务表单草稿和未提交机制状态在模块切换时保留。

视觉采用课程地图而非仪表盘堆卡：紫色启航、青色分类、杏橙回归、靛蓝模型图鉴、绿色机制与清洗，档案用安静的蓝灰。课程自动配色可由学生固定为个人偏好；颜色不更改图表中训练/验证/测试和类别的语义。界面底色、按钮、焦点、选中态和侧栏共同切换。

主要字体沿用本地中文无衬线，标题保留完整词组。字号层次与数字tabular-nums稳定；正文对比度至少4.5，主要按钮文字与背景也至少4.5。

布局：固定统一导航 | 页面标题与外观入口 | 当前学习内容。机制实验用轻量页签切换，实验下方提供对应分类/回归任务入口；不在首屏增加大段教学说明。模型/任务入口保持同一图案高度、标题槽位和底部动作基线。表单标签固定同一行槽位，帮助按钮占位一致，输入/选择器同高，说明放在控件下方。

图案：新增数据课例的小场景（企鹅冰岸、花朵/种子、票据、车与单车、建筑与混凝土、葡萄酒、多标签样本），使用统一原创SVG语言与已生成Q版岛屿、向导搭配。图案识别任务，真实图像和数值仍由训练结果决定。训练步骤加轻量工具图标和当前学习目标，不制造完成分数。

验收：统一导航不重载文档、浏览器后退/刷新能定位、任务草稿不丢、原成绩不变；1366/1440桌面、768平板、390手机无页面溢出；输入框顶边、卡片动作与大小命中区域实际测量；减少动效、键盘焦点及真实训练/原学习闭环回归保留。
