## 发现与修正

初次课程截图暴露0.8横排样式覆盖，图片挤在窄列；修正选择器并改为桌面三列、手机单列后重拍。浏览器提示课程封面为LCP且延迟加载，改为首屏及时加载。一次回到A/B时显示参考复算失败；刷新后实际复算成功并恢复两侧准确率，没有把失败状态解释成模型结果。早先一次工具导航角色未命中，读取当前导航名称后使用实际名称。

过程导出检查发现异步wait输出仍含图片二进制；增加过滤并验证保留同一输出中的文本与失败证据，原始素材和选定截图单独保留。最终全套Python为75项，前端21项。一次将npm脚本误写成npm子命令，改用npm run test:ui后完整通过。

图片原始RGBA保留alpha，由Next Image优化展示，没有把生成道路、物件当作计算数据。新增图像没有遮盖科学画布。键盘名称和焦点保留，代码包含减少动效规则。没有执行完整屏幕阅读器或真实学生试用研究，不能由画面改善推断学习成绩提高。
