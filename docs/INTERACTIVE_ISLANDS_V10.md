# 0.10 · 岛内物件与实算联动

用户要求把四座岛内部也形象化，场景物件与滑块、拖拽和真实计算联动，加入学生互动玩法，保留真实Git和脱敏AI过程。本轮使用现有插画体系与代码绘制的可操作SVG物件，不让静态生成图承担科学数据。

## 方案复核

对象、当前数值与主要操作放在同一工作区，精确图表随后展开阅读。避免在既有长页顶部再堆装饰卡片：场景作为一个连续舞台，配一个紧邻的操作/任务区。高校初学者可先操作物件，再看相同数值的图表。配色延续梅紫#28213D、紫#7546C8、青绿#087E75、薄荷#E7F2EB及珊瑚#E98275；系统中文字体，正文14～16px，辅助至少12px。图形坐标和结果文字可核对。

```text
当前概念与状态
可操纵场景物件            当前样本 / 控制 / 任务
实际数值与解释            观察 → 作答 → 核验回执
精确图表、模型参数及实算依据
```

| 岛 | 场景操作 | 实算联动与玩法 |
|---|---|---|
| 误差湖 | 拖训练浮标；调整船帆斜率、船身截距 | 同一y刻度显示观测与模型预测，残差标尺随计算变化；任务降低可减少的训练误差，再核对验证方向 |
| 曲线山 | 拖同一训练路钉；改B阶数与共同α | 两条道路来自真实配对曲线，原路用虚线；比较扰动后A/B的变化RMS，由学生判断谁变化更大 |
| 约束花园 | 转动离散α旋钮；改变模型阶数 | 植株高度来自同一标准化基下的系数绝对值，弱约束虚影共用刻度；先收缩系数，再判断验证误差方向 |
| 边界森林 | 拖验证样本包裹到类别门，或按门按钮投递；换模型 | 核对学生投递与真实模型预测，区分真实类别；固定错分样本尝试修复，同时展示全体验证指标的变化 |

## 数据与状态

复用/concepts/run和/classification/run，不新增模拟指标。请求未匹配时标注最近实算，禁用任务判分、投递与保存回执。场景中即时拖动位置只是输入预览；模型形状和指标等待后端匹配。验证样本包裹仅作选择/投递，不修改坐标或标签。

探索任务与正式课程成绩分开。任务起点从实际返回结果记录；比较要求数据、验证身份及相应固定条件一致。条件改变即提示重新布置，旧答案不套到新参数。挑战会布置明确条件，并保留一键返回原实验；回执包含当前参数、指纹、实际数值与选择，仅在已核验的当前结果下可复制。任务本身为本页练习，原有探索参数继续恢复。

## 交互与验证

原生滑块、按钮与样本选择均提供拖动替代，SVG物件保留可见焦点和键盘；减少动态效果时取消形变过渡。布局检查320/390/768/1024/1440px。检验异步旧结果、数据变化、零变化/并列、边界坐标与离散旋钮，以及正式学习门禁、原3/3现场。依据真实反馈逐项修正后提交实现与记录。学生兴趣和学习效果仍需真实试用验证。

已实现上述范围。起点独立计算修复快速操作衔接；系数窗口可手动放大并显示超窗；森林补充实际特征与区域小地图，使投递有观察依据。最终75项Python、26项前端逻辑、类型与构建通过；实际Chrome交互及20种布局结果见[验收记录](VALIDATION_V10.md)。
