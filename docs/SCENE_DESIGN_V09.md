# 0.9 · 以场景和物件组织教学入口

用户明确指出0.8仍是色块与文字式界面，希望概念岛本身就是可识别、可点击的图案，并把这种表达推广到其他位置。本轮重点是图像语义与教学氛围。

## 参考观察

- [Duolingo官方核心标签改版](https://blog.duolingo.com/core-tabs-redesign/)：核对文章及设计图，关注统一视觉语言、层级和角色反馈；插画需要服务当前功能，而非强行占据每个标题。
- [Code.org/CodeAI学生入口](https://code.org/en-US/students)：实际查看用游戏、作品和角色图像呈现课程入口，图像预告进入后可以做什么。
- [PhET数学与统计模拟目录](https://phet.colorado.edu/en/simulations/filter?subjects=math-and-statistics&type=html)：实际查看按实验画面选择内容的目录，用对象与操作建立主题辨识。

使用公开页面与设计资料，不复制这些网站的角色、图片或品牌。角色风格面向高校初学者保持轻松，数据图仍清晰、准确。

## 统一场景资产

内置image_gen生成四张原创透明底微缩场景，原始PNG与完整提示词固定至public/illustrations/world-v09。数值不写入生成图。

| 场景 | 可辨认物件 | 对应概念 |
|---|---|---|
| 误差湖 | 放大镜、偏离靶心的标记、测量杆、平方块 | 距离、残差与平方损失 |
| 曲线山 | 平滑道路、曲折道路、珠点路标 | 模型复杂度与扰动响应 |
| 约束花园 | 调节旋钮、受支架引导的藤蔓 | 参数约束与拟合取舍 |
| 边界森林 | 分类围栏、不同形状物件、观察向导 | 类别、边界与错分 |

这些是概念比喻和导航插画；模型输出、真实样本和统计指标继续由代码与数值后端产生。

## 界面落实

1. 首页改为插画主导的群岛入口，图案本身是按钮；点击或Enter直接进入相应模块，悬停/聚焦预览问题与步骤。
2. 概念面板的三个主题选择器和当前章节使用相同场景，帮助跨页识别。
3. 分类玩法选择用有形象的图卡解释自由探索、侦探和A/B对照；保留原模式名称和操作语义。
4. 正式课程路径使用场景封面，预测入口用章节图案识别主题；完成情况仍取自现有真实记录。
5. 保留可见中文名称、焦点、键盘和减少动效；四张图片预留尺寸，由Next Image按展示尺寸优化。动作按钮、数据符号继续使用一致的矢量系统。

色彩延续深梅紫#28213D、紫#7546C8、青绿#087E75，场景辅以浅薄荷#E7F2EB、暖金#D9AF5D和珊瑚#E98275。中文使用本地系统字体，标题32～38px、正文14～16px、辅助文字至少12px。把视觉表现重点放在可点击场景，画布内不增加装饰遮挡。

## 验收范围

验证各图像加载与键盘直接进入、概念切换、玩法及课程封面、五档宽度、关键玩法回归。操作性验收使用独立浏览器来源的草稿，保留原工作区学习状态。继续真实Git与脱敏AI开发记录，正式提交材料暂缓。

已落实上述范围，并增加最近六个已核验错分的标本回看。实际截图发现课程封面受旧横排样式挤压，改为桌面三列/手机单列后重拍；首屏课程图像及时加载。最终75项Python、21项前端逻辑与生产构建通过，20种视图/宽度组合无页面横向溢出。具体记录见[0.9验收](VALIDATION_V09.md)。
