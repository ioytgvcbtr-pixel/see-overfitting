# 模力星球的数据与本机记录

## 内置数据

- `planet/`：分类与回归任务使用的公开数据快照、来源、许可及处理说明，见[数据目录](planet/README.md)。
- `public/`：共享数值实验使用的公开快照与[来源清单](public/manifest.json)。
- 教学合成数据由后端按固定种子生成，明确标注为合成条件。

数据快照随项目提供，核心数值实验不依赖在线下载。训练、验证和测试身份由后端保存；清洗与特征处理只在实际训练子集上拟合。已接触过的测试身份继续保留接触标记。

## 本机学习记录

`fitlab.sqlite`由应用维护，保存课程进度、首答、实验及学习档案状态，由Git忽略。API密钥保存在本机配置中，不写入公开数据或学习导出文件。

学习档案通过网页中的完整JSON导出、导入、重置与撤销操作管理；清理构建文件不应删除此数据库。
